# Демо-данные

Синтетические переписки для демо «Это точно Саша?» (сценарий — `docs/IDEA.md`). Все люди и события выдуманы, личных данных нет. Тексты сообщений написали LLM-агенты (Claude Haiku) по заданным портретам почерка персонажей; время сообщений расставляет `build.py`.

Реальные экспорты по-прежнему лежат только в `data/` и не коммитятся.

## Файлы

Все `.json` — экспорт Telegram Desktop (JSON), загружаются через `POST /api/chats`.

| Файл | Что внутри | Для какого шага демо |
|---|---|---|
| `personal_main.json` | личка Данила ↔ Саша, март–октябрь 2026, 652 сообщения | паспорт почерка Саши, проверка сообщений |
| `checks.txt` | 8 настоящих сообщений в стиле Саши и 8 фейков от «взломанного» аккаунта | проверка: вставить текст и проверить против Саши |
| `group_twins.json` | групповой чат «Студсовет: движ», 6 участников, 786 сообщений; Дима и Миша — один человек | двойники |
| `personal_alt.json` | личка Данила ↔ Alex (второй аккаунт Саши), 270 сообщений | сравнение двух чатов вместе с `personal_main.json` |

## Персонажи

- **Саша / Alex** — с маленькой буквы, без точки в конце, скобки вместо эмодзи, «ща», «кста», «норм», «го», «прив»; никогда не пишет «Привет», «срочно», «пожалуйста».
- **Данила** — заглавные, точки, полные слова.
- **Дима и Миша** — общие «щас», «короч», «токо», «ваще», «чел», «!!», пробел перед «?»; никогда не пишут в одну минуту и сменяют друг друга за ~30 с. Остальные участники этих привычек не используют.

Факты для контрольного вопроса: концерт «Синих огней» в мае, бар «Хмель и солод» после него, потерянный наушник, поездка в Казань, кот Бублик.

## Что выдаёт бэкенд (без LLM-ключа)

- Паспорт Саши: пишет с маленькой буквы — 100%, не ставит точку — 100%, скобки — 39%.
- Фейки из `checks.txt` — все `mismatch` (0.00–0.07). Лучше всего узнаются настоящие «бублик опять на клаве уснул)», «ща гляну, кинь ошибку», «кста ты фикстуру для /compare уже поправил».
- Двойники: Дима–Миша `likely_same` 0.91 со всеми уликами (почерк, общие редкие слова, привычки, 0 общих минут, переключение 40 с против 98 с у остальных); следующая пара — 0.33.
- Сравнение `personal_main` и `personal_alt`: Саша–Alex `likely_same` 0.89.

## Пересборка

`source/*.jsonl` — сырые реплики агентов (`{"day", "from", "text"}`, без времени). Скрипт растягивает дни по датам, раскладывает сообщения по часам активности каждого персонажа и следит за таймингом двойников. Результат детерминирован:

```bash
python3 demo/build.py demo/source demo
```
