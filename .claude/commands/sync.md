---
description: Подтянуть свежий main в текущую ветку через rebase
---

1. Если есть незакоммиченные изменения — сначала закоммить их (осмысленное сообщение) или остановись и спроси меня.
2. `git fetch origin`
3. `git rebase origin/main`
4. Конфликты:
   - в lock-файлах не правь руками: возьми версию из `main` (`git checkout --theirs`/`--ours` с учётом направления rebase) и переустанови зависимости;
   - в чужой зоне — возьми версию из `main`;
   - в остальном разреши аккуратно, сохранив смысл обеих сторон; если неочевидно — покажи мне.
5. Запусти тесты и линт.
6. Если ветка уже была запушена, предложи `git push --force-with-lease` и жди моего ок. Никогда не `--force`.
