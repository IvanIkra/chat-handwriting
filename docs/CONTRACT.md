# Контракт между зонами

Источник истины для API и форматов данных. Меняется только через `/contract` отдельным PR, который подтверждают оба.

## Общее
- Базовый URL (локально): `http://localhost:8000`
- Формат: JSON, UTF-8, даты в ISO 8601 (UTC)
- Ошибки: HTTP-статус + тело `{"error": {"code": "string", "message": "string"}}`
- Авторизация: <нет / заголовок `Authorization: Bearer <token>`>

## Сущности

### Item (пример — заменить)
```json
{
  "id": "string",
  "title": "string",
  "created_at": "2026-10-25T12:00:00Z"
}
```

## Эндпоинты

### `GET /api/items`
Ответ `200`:
```json
{ "items": [ { "id": "1", "title": "Пример", "created_at": "2026-10-25T12:00:00Z" } ] }
```

### `POST /api/items`
Запрос:
```json
{ "title": "string" }
```
Ответ `201`: объект `Item`. Ошибка `400`: `{"error": {"code": "validation", "message": "..."}}`

## Моки
Пока бэкенд не готов, фронтенд использует примеры ответов из этого файла как моки.
