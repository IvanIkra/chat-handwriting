# Хакатон вдвоём на Claude Code — запуск

## До старта (15 минут, вместе)
1. **Один человек** создаёт репозиторий на GitHub, копирует туда всё содержимое этого набора (включая скрытые `.claude/`, `.github/`, `.gitignore`, `.env.example`) и пушит в `main`.
2. Он же запускает:
   ```bash
   gh auth login
   chmod +x setup-github.sh && ./setup-github.sh <логин-напарника>
   ```
3. **Оба** у себя:
   ```bash
   git clone <url> && cd <repo>
   cp CLAUDE.local.md.example CLAUDE.local.md   # вписать своё имя и зону
   cp .env.example .env                          # реальные ключи передать лично, не через git
   gh auth login
   ```
4. **Вместе, 20–30 минут, до первой строчки кода:**
   - заполнить в `CLAUDE.md` стек, команды и зоны;
   - набросать `docs/CONTRACT.md` (сущности и эндпоинты — хватит примеров);
   - сделать скелет проекта одним PR (папки зон, пустые сервисы, работающий «hello world») — это единственный момент, когда оба трогают всё;
   - нарезать 10–20 issues с метками `zone:A` / `zone:B` / `shared`.

## Цикл работы (у каждого)
```
/status            — что нового, нужно ли синхронизироваться
/task 12           — взять issue #12: assign, ветка, план
... пишем с Claude ...
/sync              — подтянуть main (делать каждые ~30–60 мин)
/ship              — проверки, push, PR с Closes #12
```
Изменение API между зонами — только `/contract "<что нужно>"`, мержится после ок второго.

## Два терминала / параллельные задачи у одного человека
Если хочешь запустить второй Claude Code на другую задачу на той же машине — не в той же папке, а в worktree:
```bash
git worktree add ../<repo>-14 -b 14-something origin/main
cd ../<repo>-14 && cp ../<repo>/CLAUDE.local.md ../<repo>/.env . && claude
```

## Связь
- Голос/чат открыт всё время. Перед мержем в `shared/` или контракта — написать напарнику.
- Каждые 2–3 часа короткий синк: что смержено, что дальше, не пора ли резать скоуп.
- За 2 часа до дедлайна — фриз фич: только баги, демо и презентация.

## Что в наборе
| Файл | Зачем |
|---|---|
| `CLAUDE.md` | общие правила для обоих Claude: зоны, git-процесс, контракт |
| `CLAUDE.local.md.example` | личное: кто я, моя зона (копия в git не попадает) |
| `.claude/settings.json` | разрешения: git/gh без лишних вопросов, запрет пушей в main, force-push, чтения `.env` |
| `.claude/commands/` | `/task`, `/sync`, `/ship`, `/contract`, `/status` |
| `docs/CONTRACT.md` | контракт API между зонами — источник истины |
| `.github/pull_request_template.md` | шаблон PR |
| `setup-github.sh` | метки, приглашение напарника, squash-only, защита main |
